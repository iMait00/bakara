## المميزات

- 🎬 **فيديو من أي موقع** — YouTube وأكثر من ألف موقع، بأعلى جودة متوفرة
- 📁 **مجلدات Google Drive كاملة** — بدون تقسيم zip وبدون توقّف بسبب حظر التحميل
- ✂️ **قص قبل التحميل** — تحدّد البداية والنهاية وتنزّل الجزء اللي تحتاجه بس
- 💬 **ترجمة SRT** — يقراها بريمير ودافينشي وكاب كت مباشرة
- 🖼️ **صور العرض** — الثمبنيل بأعلى دقة
- 🎵 **فيديو أو صوت** — MP4 / MOV / AVI أو MP3 / AAC / Opus
- 🎚️ **إزالة الموسيقى** — يفصل التعليق عن الخلفية الموسيقية
- 📋 **دفعة كاملة مرة وحدة** — الصق روابط بعدد ما تبي وخلّها تشتغل
- 🔔 **يشتغل بالخلفية** — أيقونة في شريط القوائم مع لوحة سريعة، والتحميل يكمل حتى لو سكّرت النافذة
- 🌙 **واجهة عربية بالكامل** — RTL من أول زر لآخر رسالة خطأ

## التحميل

| النظام | الملف |
|--------|-------|
| Windows | `Bakara_x.y.z_x64-setup.exe` |
| macOS (Apple Silicon) | `Bakara_x.y.z_aarch64.dmg` |
| macOS (Intel) | `Bakara_x.y.z_x64.dmg` |

كل الملفات في [صفحة الإصدارات](https://github.com/iMait00/bakara/releases/latest).

**أول تشغيل:** التطبيق ينزّل أدواته بنفسه (yt-dlp و FFmpeg و Python و Deno) — خلّ الإنترنت شغّالاً وانتظر انتهاء التهيئة.

> **macOS:** التطبيق غير موقّع بشهادة Apple — أول مرة افتحه بزر الفأرة الأيمن ← **Open** ثم أكّد.
